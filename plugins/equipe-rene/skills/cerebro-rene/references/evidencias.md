# Referências de evidência

Use estas referências para sustentar afirmações. Cite o construto, não exagere o efeito.

| Referência | O que sustenta |
|---|---|
| Judge, Piccolo e Ilies (2004) | Consideração (0,48) e estruturação (0,29) se relacionam com resultados da liderança |
| Judge e Piccolo (2004) | Recompensa contingente (0,39): reconhecer de forma ligada ao comportamento |
| Dirks e Ferrin (2002) | Confiança no líder |
| Gerstner e Day (1997) | Qualidade da relação líder-liderado |
| Kluger e DeNisi (1996) | Feedback: o efeito médio é positivo, mas cerca de um terço das intervenções piora o desempenho |
| Skogstad (2007) | Liderança omissa (laissez-faire) é destrutiva, não neutra |
| Owens (2013) | Humildade do líder |
| Lee, Willis e Tian (2018) | Liderança que empodera e delegação |
| Burke (2006) | Comportamentos de liderança e efetividade da equipe |

| Frazier (2017) | Clareza de papel |
| Mayer (2009) | Liderança em cascata: o comportamento de quem está acima influencia o de baixo |
| Griffeth (2000) | Preditores de rotatividade (não prometa reduzi-la) |
| van Knippenberg e Sitkin (2013) | Crítica ao modelo genérico de liderança transformacional |

## Como usar

- Efeitos de programas de liderança são de pequenos a moderados.
- Uma pesquisa sustenta uma relação, não garante um resultado para um mentorado específico.
- Em anúncios e páginas, prefira não citar números de correlação. Use a pesquisa para escolher o que prometer, não para impressionar.
